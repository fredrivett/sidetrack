# Learnings

Captured agent learnings awaiting review. Each entry is a candidate harness
improvement — once promoted, the entry is deleted and the rule/test/hook lives
in its real home (`eslint.config.mjs`, `src/**/*.test.ts`, `.claude/settings.json`,
or `AGENTS.md`).

Append via `/learn` (see `.agents/skills/learn/SKILL.md`). Triage in batches.

## Triage flow

For each entry, pick one:

1. **Promote.** Write the rule/test/hook in its real home and delete the
   entry. This is the goal — one durable harness change per recurring defect.
2. **Park as note.** Keep in this file under "Cold notes" if it's genuinely
   useful context but doesn't justify a deterministic check yet.
3. **Reject.** Delete the entry. One-off bugs don't earn permanent rules.
